# Тест-кейсы для валидации конфигурационного файла

## 1. Позитивные сценарии (Классы эквивалентности)
| ID | Описание | Входные данные (JSON) | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Валидный файл со всеми полями | `{"host": "localhost", "port": 8080, "timeout": 30, "enabled": true}` | `True` |
| TC-02 | Граничные значения (мин) | `{"host": "a", "port": 1, "timeout": 1, "enabled": false}` | `True` |
| TC-03 | Граничные значения (макс) | `{"host": "test", "port": 65535, "timeout": 300, "enabled": true}` | `True` |
| TC-04 | Timeout дробное число | `{"host": "localhost", "port": 8080, "timeout": 1.5, "enabled": true}` | `True` |

## 2. Негативные сценарии (Ошибки полей и граничные значения)
| ID | Описание | Входные данные (JSON) | Ожидаемый результат |
|---|---|---|---|
| TC-05 | Порт ниже границы | `port: 0` | `False` |
| TC-06 | Порт выше границы | `port: 65536` | `False` |
| TC-07 | Timeout ниже границы | `timeout: 0` | `False` |
| TC-08 | Timeout выше границы | `timeout: 301` | `False` |
| TC-09 | Пустой host | `host: ""` или `"   "` | `False` |
| TC-10 | Неверный тип порта (строка) | `port: "8080"` | `False` |
| TC-11 | Неверный тип enabled (строка) | `enabled: "true"` | `False` |
| TC-12 | Отсутствует обязательное поле | Нет ключа `timeout` | `False` |

## 3. Негативные сценарии (Файловая система и JSON)
| ID | Описание | Входные данные | Ожидаемый результат |
|---|---|---|---|
| TC-13 | Файл не существует | Путь к несуществующему файлу | `False` |
| TC-14 | Некорректный JSON | `{"host": "localhost",` (обрезанный) | `False` |
| TC-15 | JSON не является объектом | `[1, 2, 3]` | `False` |
